# `telescope.nvim`

Provides fuzzy file, text, buffer, and Git search.

- Configuration: [`telescope.lua`](../../lua/plugins/telescope.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: `brew install ripgrep fd`; install Git with `xcode-select --install` for Git pickers.

## Use

Use the `<leader>f` find mappings and `<leader>g` Git pickers.
