# `lazydocker.nvim`

Opens LazyDocker inside Neovim.

- Configuration: [`docker.lua`](../../lua/plugins/docker.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: `brew install lazydocker`; install and start Docker Desktop separately.

## Use

Open it with the configured LazyDocker command or mapping; check with `:checkhealth lazydocker`.
