# `conform.nvim`

Formats buffers with external formatters.

- Configuration: [`format.lua`](../../lua/plugins/format.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: Lua formatting: `brew install stylua`.

## Use

Run the configured formatting mapping, `<leader>cF`; inspect with `:ConformInfo`.
