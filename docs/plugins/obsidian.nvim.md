# `obsidian.nvim`

Adds vault navigation, links, and note commands.

- Configuration: [`obsidian.lua`](../../lua/plugins/obsidian.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: `brew install ripgrep`; set `OBSIDIAN_VAULT=/path/to/vault`. The Obsidian app is optional except for app-opening commands.

## Use

Open a Markdown file inside the configured vault and run `:Obsidian` commands.
