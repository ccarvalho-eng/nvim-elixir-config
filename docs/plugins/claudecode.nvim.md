# `claudecode.nvim`

Integrates the optional Claude Code CLI.

- Configuration: [`ai.lua`](../../lua/plugins/ai.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: Optional: `npm install -g @anthropic-ai/claude-code`, then run `claude --version`.

## Use

Use the `<leader>ac` mappings after installing and authenticating the CLI.
