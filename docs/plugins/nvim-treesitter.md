# `nvim-treesitter`

Provides parser-based highlighting and text awareness.

- Configuration: [`treesitter.lua`](../../lua/plugins/treesitter.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: `brew install tree-sitter-cli`; run `xcode-select --install` for a C compiler. macOS supplies `curl` and `tar`.

## Use

Configured parsers install automatically; update them with `:TSUpdate`.
