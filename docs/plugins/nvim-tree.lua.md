# `nvim-tree.lua`

Provides the file explorer.

- Configuration: [`tree.lua`](../../lua/plugins/tree.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: Git from `xcode-select --install`; recommended: `brew install --cask font-fira-code-nerd-font` for icons.

## Use

Toggle it with `<leader>e`.
