# `nvim-web-devicons`

Provides file and UI icons to other plugins.

- Configuration: [`ui.lua`](../../lua/plugins/ui.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: `brew install --cask font-fira-code-nerd-font`.

## Use

Installed automatically as a dependency and used by compatible UI plugins.
