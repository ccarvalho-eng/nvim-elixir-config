# `vim-dadbod-ui`

Provides a database browser and query interface.

- Configuration: [`db.lua`](../../lua/plugins/db.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: The matching database client required by `vim-dadbod`.

## Use

Open it with `:DBUI`; configure connections through environment variables.
