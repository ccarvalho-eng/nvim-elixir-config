# `render-markdown.nvim`

Renders Markdown structure and decorations inside Neovim.

- Configuration: [`ai.lua`](../../lua/plugins/ai.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: Recommended: `brew install --cask font-fira-code-nerd-font` for symbols.

## Use

Loads automatically for Markdown buffers.
