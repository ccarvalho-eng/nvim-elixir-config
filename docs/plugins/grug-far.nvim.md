# `grug-far.nvim`

Provides project-wide search and replace.

- Configuration: [`telescope.lua`](../../lua/plugins/telescope.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: `brew install ripgrep` (version 14 or newer).

## Use

Use the `<leader>s` search-and-replace mappings.
