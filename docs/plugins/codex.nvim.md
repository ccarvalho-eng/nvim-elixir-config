# `codex.nvim`

Integrates the optional Codex CLI.

- Configuration: [`ai.lua`](../../lua/plugins/ai.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: Optional: install the [Codex CLI](https://learn.chatgpt.com/docs/codex/cli), then run `codex --version`.

## Use

Use the `<leader>ao` mappings after installing and authenticating the CLI.
