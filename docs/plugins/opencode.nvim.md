# `opencode.nvim`

Connects Neovim to OpenCode and the configured Ollama models.

- Configuration: [`ai.lua`](../../lua/plugins/ai.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: `brew install anomalyco/tap/opencode`; install Ollama and models using the linked local-model guide.

## Use

Use `<leader>ap`; choose a model with `<leader>apm`. See [OpenCode and Ollama](../opencode-ollama.md).
