# `cmp-nvim-lsp`

Adds language-server suggestions to completion.

- Configuration: [`completion.lua`](../../lua/plugins/completion.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: Install the language servers you use; this configuration includes `brew install lua-language-server` for Lua.

## Use

Loads automatically when an LSP server is attached.
