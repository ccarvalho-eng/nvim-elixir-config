# `bufferline.nvim`

Displays and manages open buffers as tabs.

- Configuration: [`ui.lua`](../../lua/plugins/ui.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: Recommended: `brew install --cask font-fira-code-nerd-font` for icons.

## Use

Use the `<leader>b` mappings defined in the configuration.
