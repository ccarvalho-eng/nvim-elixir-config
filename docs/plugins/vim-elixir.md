# `vim-elixir`

Provides Elixir syntax and file-type support.

- Configuration: [`lsp.lua`](../../lua/plugins/lsp.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: None for syntax support. Language runtime installation is intentionally outside this guide.

## Use

Loads automatically for Elixir-related file types.
