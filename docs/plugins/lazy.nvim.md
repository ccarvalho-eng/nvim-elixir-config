# `lazy.nvim`

Bootstraps and manages all Neovim plugins.

- Configuration: [`../config/lazy.lua`](../../lua/config/lazy.lua)

## Installation

1. Start Neovim; the bootstrap code clones Lazy.nvim automatically.
2. System dependency: Git from `xcode-select --install`, plus internet access for the initial clone.

## Use

Run `:Lazy sync` after cloning or changing plugin definitions.
