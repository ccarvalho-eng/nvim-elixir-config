# `diffview.nvim`

Shows Git diffs and file history in Neovim.

- Configuration: [`git.lua`](../../lua/plugins/git.lua)

## Installation

1. Run `:Lazy sync` to install the Neovim plugin.
2. System dependency: Git, provided by `xcode-select --install`.

## Use

Run `:DiffviewOpen`, `:DiffviewFileHistory`, or `:DiffviewClose`.
