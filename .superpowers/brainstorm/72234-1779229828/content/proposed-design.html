Proposed MVP design

A lightweight app that turns a rough traced floor plan into an explorable first-person 3D shell.

Workflow
1. Upload

PNG, JPG, or PDF page.

2. Scale

Mark one known wall length.

3. Trace

Draw walls, doors, and openings.

4. Generate

Extrude to wall height.

5. Walk

Move in first person.

In scope

  • Local browser app using React or similar UI stack.
  • PDF/image import, page rendering, pan/zoom, scale calibration.
  • Snapping wall tracer, door/opening markers, wall height/thickness settings.
  • Three.js 3D scene with first-person controls and minimap.

Out of scope

  • CAD precision, automatic blueprint recognition, roof modeling, multi-floor plans.
  • Cloud storage, user accounts, collaboration, and construction-grade export.
